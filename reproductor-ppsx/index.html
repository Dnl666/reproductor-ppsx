¿Cómo obtengo el enlace correcto de OneDrive?
  1. Abre la presentación en OneDrive (PowerPoint para la web).
  2. Ve a Archivo → Compartir → Insertar y pulsa Generar.
  3. Copia el código o solo el enlace src y pégalo arriba. El enlace de “Copiar vínculo” normal no se deja insertar.
  4. Un archivo .ppsx arrastrado aquí se dibuja en el navegador: conserva textos, imágenes, audio, botones y animaciones básicas (aparecer, desaparecer, desplazar).

Insertar en tu web o LMS

  • &titulo=Mi%20curso — texto en la pantalla de inicio
  • &inicio=directo — sin botón de inicio (el navegador puede silenciar el audio hasta el primer clic)
  • &ui=1 — muestra el botón para cambiar de presentación
  • &color=4C8DFF — color de acento
